# Agent Task Completion Audit

Use this for routes where the real question is whether a human or AI agent can finish the job, not just read the page.

## Core Checks

- `Discoverable`: can the task entry point be found from the page or route where the job starts.
- `Initiatable`: can the user tell what to click, tap, or submit without guessing.
- `Completable`: can the task finish without broken links, missing fields, or dead-end copy.
- `Traceable`: is the submit path measurable after the action completes.

## Seascape Priority Flows

- owner revenue review forms
- booking or inquiry forms
- key contact and follow-up routes

## Audit Receipt

- starting URL
- target action
- blockers or drop points
- evidence captured: route readback, screenshot, form response, or tracking proof
- exact next fix if the task stalls
