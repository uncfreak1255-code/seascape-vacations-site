# SEO Cannibalization Checklist

Use this before rewriting titles, H1s, intros, or primary internal-link targets for an SEO batch.

## Checks

- Name the canonical winner URL for the query family before editing copy.
- List the feeder pages that should support the winner instead of competing with it.
- Pull the live query-to-URL split from GSC or the joined BigQuery report before assuming the wrong page is ranking.
- Compare title, H1, intro, and CTA intent across the competing pages and mark what must stay distinct.
- Confirm which page owns the main conversion ask and which pages should only route into it.
- Decide whether a competing page should be rewritten, downscoped, redirected, or left alone.
- Verify the internal-link plan after the rewrite so feeder pages point at the winner on purpose.
- Write down the post-change measurement check before shipping: impressions, CTR, position, clicks, and conversion path.

## Default Stop Conditions

- Stop if the current winner is still unknown.
- Stop if two pages still need the same title or H1 to do their jobs.
- Stop if the rewrite would change metadata during a freshness-blocked window.
