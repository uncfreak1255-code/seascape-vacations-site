Decision boundary

This board supports review only. A copied draft is not a send, a send is not demand, and no row here can update the Hub demand register.

Founder send check

  1. Open the listing and confirm the public host surface still matches the row.
  2. Make the note personal and one-to-one.
  3. Do not imply the owner is losing money or unhappy.
  4. Prepare the send-log row before any real send.

Proof rules

  • Named public host label.
  • Reopenable listing evidence.
  • Platform contact path only.
  • One approved proof module: gulf-coast-owner-benchmark-2026.
  • No private data, scraping, property records, or demand claim.
