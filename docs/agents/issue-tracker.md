# Issue tracker: GitHub

Issues and specs live in `uncfreak1255-code/seascape-vacations-site`.
Use the connected GitHub tools or `gh` with that explicit repository.
Read the issue body and comments before acting; use `--body-file` for
multiline CLI writes. A skill's instruction to publish a spec means create
an issue within the authorized task. A supplied local spec remains valid
for a local review; publication is not a review prerequisite.

PRs as a request surface: no. Resolve an ambiguous number as a PR or issue
before reading it. Link child tickets with native sub-issues and dependencies
when supported; otherwise use a parent task list, `Part of #<parent>` and
`Blocked by: #<number>` in child bodies.

Issues and readiness labels describe work; AGENTS.md governs its authority,
required reviews, publication and production effects.
