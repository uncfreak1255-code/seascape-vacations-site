# Triage labels

| Role and label | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation needed |
| needs-info | Waiting for reporter information |
| ready-for-agent | Fully specified for agent implementation |
| ready-for-human | Human implementation required |
| wontfix | Will not be actioned |

Use these labels when the corresponding triage role applies. Readiness
never authorizes a send, spend, production change, or bypass of Site gates.
