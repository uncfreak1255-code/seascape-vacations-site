# Domain conventions

Single-context layout: read root `GLOSSARY.md` and relevant decisions under
`docs/adr/` before domain exploration or modeling. Missing ADRs are not a
setup blocker; create a decision record only when a task resolves a decision.

Use established vocabulary in specs, issues and code. Existing Site process,
brief, design and business-source rules remain authoritative; a glossary or
ADR does not grant approval or replace those sources. Surface contradictions
with the owning source before relying on a term or decision.
