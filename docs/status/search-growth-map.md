## Operating Rules

- Start with the business outcome: owner lead quality, direct-book handoff, or
  guide-to-money transfer.
- Keep each query family tied to one current winner URL or mark it as
  `missing page`.
- Use competitors, SERP shape, and AI-answer gaps as demand sensors, not as
  permission to create page volume.
- Do not edit titles, descriptions, or snippet-focused copy while
  `docs/status/next-batch.md` says `blocked by freshness`, unless Sawyer
  explicitly overrides the gate.
- Allowed during freshness blocks: SERP gap research, competitor/query
  research, internal-link cleanup, schema/source-truth repair, brief prep, and
  proof-safe page-quality notes.
- Do not claim AI citation, owner demand, direct-book revenue, or conversion
  lift without analytics receipts or source proof.
- Keep validation dates date-only unless a machine receipt provides a more
  specific run timestamp.

## Agent Readback Contract

When an agent uses this map, it should report:

- `Query family:`
- `Intent:`
- `Current URL:`
- `Proof lane:` what is claim-blocked, stale, or waiting on
  `docs/status/next-batch.md`
- `Attack lane:` the useful bounded move, or `none found` after source and SERP
  checks
- `Next action:` one concrete action, not a vague hold

If an agent cannot name the query family, current URL, and attack lane, it has
not finished the SEO/GEO cycle.
