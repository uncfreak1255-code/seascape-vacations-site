# Page-specific CRO lenses

Use the section matching the page's job.

- **Homepage:** positioning for new visitors, a clear path to the main conversion,
  and paths for both ready-to-book and researching visitors.
- **Landing page:** match the referring message and offer, make the primary action
  clear, and provide enough evidence to decide. Navigation removal is a hypothesis,
  subject to accessibility, internal-link requirements, and the page's actual job.
- **Pricing:** make comparisons and value differences clear; help visitors choose
  without invented popularity, guarantees, or savings claims.
- **Feature or property page:** connect features to visitor needs with factual
  examples and a clear next step.
- **Blog or guide:** place contextual CTAs at natural decision points; preserve
  the article's answer and reading experience.
- **Forms:** inspect field necessity, labels, validation, errors, and successful
  completion. Use safe local fixtures for submissions under repository rules.
