# Web Design Guidelines

Explicit-invocation compatibility entry for Seascape UI review. Use
`design-review` for the rendered review contract and relevant evidence, and
`DESIGN.md` for visual law. This entry remains explicitly invoked; it does not
add another automatic review pass.

Check the intended route and visible state on desktop/mobile. Interaction
claims require exercised controls and observed results. Return findings with
source paths, viewports, evidence, and smallest fixes; a clean review names the
screenshots and checks examined. Follow the existing design-review workflow
before calling a visual change ready.
