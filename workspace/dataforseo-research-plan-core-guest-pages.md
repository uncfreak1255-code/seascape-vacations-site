# DataForSEO Research Plan - Core Guest Money Pages

This plan covers queue item 1 only:
- `/`
- `/properties/`
- `/stays/book-direct-anna-maria-island/`
- `/stays/anna-maria-island-vacation-rentals/`
- `/stays/bradenton-vacation-rentals-near-beaches/`
- `/stays/sarasota-vacation-rentals-with-pool/`

## Goal

Use DataForSEO credits to answer four questions before changing any page:
- What exact query is each page really competing for?
- What SERP features are shaping the click before organic results matter?
- Is the page angle aligned with what Google is rewarding now?
- Is AI search summarizing the query in a way that changes the page's job?

## Use These DataForSEO Surfaces First

1. `Google Organic SERP Advanced`
- Use this first because it gives the full SERP shape instead of just blue links.
- This is the main research surface for these pages.

2. `Google AI Mode SERP Advanced`
- Use this second on a smaller set of natural-language queries.
- Run only after the Organic pass so credits stay focused.

3. `DataForSEO Labs`
- Use after the first SERP pass if we need volume, difficulty, or adjacent-keyword expansion.
- Do not start here. First we need live SERP truth.

## First Run Configuration

- Language: `en`
- Device order: `mobile` first, then `desktop` for winning or confusing queries
- Geography order:
- `United States` for broad travel-planning intent
- `Bradenton, FL` overlay only for Bradenton pages and ambiguous local terms
- `Sarasota, FL` overlay only for Sarasota pages and ambiguous local terms

## Run Order

1. Run every `Priority 1` query through `Google Organic SERP Advanced` on `mobile` in `United States`.
2. Repeat only the strongest two queries per page on `desktop`.
3. Run every `AI Mode` query through `Google AI Mode SERP Advanced`.
4. If a query is highly local or confusing, rerun it with the city overlay.
5. Only after that decide whether any page needs a rewrite, angle shift, or no change.

## What To Record For Each Query

- Presence or absence of `ai_overview`
- Presence or absence of `local_pack`
- Presence or absence of `people_also_ask`
- Top 5 organic domains
- Whether OTAs dominate or whether smaller local operators appear
- Whether Google is rewarding island, near-island, or city-based framing
- Whether the SERP is comparison-led, booking-led, guide-led, or map-led

## Fast Decision Rules

- If OTAs dominate and local operators are absent, do not rewrite copy yet. First check whether the page needs a narrower angle.
- If AI Overviews and PAA dominate, prioritize answer clarity and direct tradeoff framing over more generic inventory copy.
- If near-island terms reward honesty about drive time and geography, keep or strengthen that framing instead of trying to sound more "on-island."
- If branded queries are weak, treat homepage and entity signals as the first priority before expanding more content.
